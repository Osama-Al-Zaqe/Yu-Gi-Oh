# موسوعة YuGi — Yu-Gi-Oh! Ultimate Encyclopedia 🎴

> **الموسوعة الشاملة لبطاقات Yu-Gi-Oh! الكلاسيكية والحديثة باللغة العربية، مبنية بالكامل باستخدام الصور المحلية وقاعدة بيانات رسمية موثقة.**

---

## 📌 نظرة عامة على المشروع

مشروع **YuGi** هو تطبيق ويب متكامل وتفاعلي فائق السرعة، مصمم لخدمة عشاق ومبارزي Yu-Gi-Oh! في العالم العربي. يربط الموقع جميع ملفات الصور الأصلية المخزنة محلياً في مجلد `card/` بقاعدة بيانات تفصيلية ودقيقة بنسبة تطابق **100%**، مع واجهة مستخدم مظلمة أنيقة تدعم العربية أصلاً (RTL) وتعمل بكفاءة تامة دون الحاجة إلى اتصال دائم بالإنترنت.

## 🚀 طريقة التشغيل السريع

### على نظام Windows:
1. انقر نقراً مزدوجاً على الملف:
   ```cmd
   START.bat
   ```
2. سيقوم السكريبت بفحص وجود بيئة Python أو Node.js، وتشغيل الخادم المحلي الخفيف تلقائياً، وفتح متصفحك الافتراضي على الرابط:
   `http://localhost:8080/index.html`

### على أنظمة Linux و macOS:
افتح الطرفية (Terminal) واكتب:
```bash
chmod +x START.sh
./START.sh
```

## 🌟 المميزات والوظائف الرئيسية

### 1. البحث والفلاتر الحية الفائقة
* **بحث ذكي متعدد المسارات:** بالاسم العربي، الاسم الإنجليزي، رقم البطاقة (Passcode)، اسم ملف الصورة (مثل `4007_1`)، نص التأثير، الفئة أو العنصر.
* **فلاتر فورية متعددة وقابلة للدمج:**
  * **نوع البطاقة:** وحش، سحر، فخ.
  * **أنواع الوحوش الفرعية:** عادي (Normal)، تأثير (Effect)، قلب (Flip)، انصهار (Fusion)، طقوس (Ritual).
  * **أنواع السحر والفخاخ الفرعية:** مستمر، لعب سريع، تجهيز، ملعب، مضاد.
  * **العناصر:** DARK, LIGHT, EARTH, WATER, FIRE, WIND, DIVINE.
  * **الفئات (Races):** تنين، ساحر، محارب، شيطان، زومبي، آلة، ديناصور، حشرة، إلخ.
  * **المستوى والنجوم:** من 1 إلى 12 نجمة.
  * **نطاق الهجوم والدفاع:** فلاتر مرنة للأرقام الدقيقة.
  * **فلاتر القدرات الخارقة:** هل تدمر؟ هل تعزز الهجوم؟ هل تستدعي؟ هل تبطل؟ هل تستعيد؟
  * **الترتيب المتقدم:** حسب الهجوم، الدفاع، المستوى، الاسم أبجدياً، أو المفضلة.

### 2. نافذة التفاصيل الشاملة للبطاقة (Card Details Viewer)
عند النقر على أي بطاقة، تفتح نافذة متقدمة تعرض:
* **صورة البطاقة الأصلية بدقة عالية** مع إمكانية النقر لقلب البطاقة (Flip 3D) لرؤية الخلفية الرسمية.
* **الرسومات البديلة (Alternate Artworks):** إمكانية التبديل الفوري بين الرسومات المتعددة لنفس الوحش (مثل التنين الأبيض، ساحر الظلام، غايا، كوريبو، إلخ).
* **إحصائيات الوحوش:** الهجوم ATK، الدفاع DEF، المستوى، نوع الاستدعاء وشروطه (تضحية واحدة، تضحيتان، انصهار، طقوس).
* **بطاقات السحر والفخ:** تصنيفها وسرعتها وشروط تفعيلها دون خلط إحصائيات الوحوش معها.
* **القدرات والتأثيرات الخارقة (الإجابة على الأسئلة الـ 12):**
  * شرح عربي مبسط وتطبيقي لطريقة عمل التأثير في المبارزة.
  * النص الإنجليزي الأصلي المعتمد.
  * إيضاح قدرات التدمير، التعزيز، الاستدعاء، الإبطال، والاستعادة من المقبرة.
  * سرعة التأثير وتوقيت تفعيله (Speed 1, 2, 3) والقيود على الاستخدام والتكاليف.
  * الاستراتيجيات الموصى بها في المبارزات ونقاط القوة والضعف والبطاقات المتوافقة (Synergy).
* **المسار المحلي ومعرف Konami الرسمي.**

### 3. صانع ومحرر المجموعات (Deck Builder)
* **9 مجموعات جاهزة مبنية بالكامل على البطاقات المتوفرة محلياً:**
  1. مجموعة الظلام (Dark Deck)
  2. مجموعة التنانين (Dragon Deck)
  3. مجموعة السحر والسحرة (Spellcasters Deck)
  4. مجموعة الفخاخ والتحكم (Traps Deck)
  5. مجموعة الهجوم القوي (Beatdown Deck)
  6. مجموعة الدفاع الحصين (Wall Deck)
  7. مجموعة الوحوش ذات التأثيرات (Effect Monsters Deck)
  8. مجموعة البطاقات الكلاسيكية (Nostalgia Deck)
  9. مجموعة المفضلة (Spotlight Deck)
* **صانع المجموعات المخصصة:**
  * إنشاء وحفظ مجموعات لا نهائية محلياً (localStorage).
  * إضافة وحذف البطاقات وضبط عدد النسخ (من 1 إلى 3 نسخ وفق القواعد الرسمية).
  * إحصائيات حية للمجموعة: عدد الوحوش، السحر، الفخاخ، متوسط الهجوم والدفاع، والتحقق من اكتمال الحد الأدنى القانوني (40 بطاقة).
  * تصدير واستيراد المجموعات بصيغة JSON.
  * إمكانية استنساخ أي مجموعة جاهزة لتعديلها.

### 4. أداة مقارنة البطاقات (Card Comparison Tool)
* مقارنة حية بين بطاقتين أو 3 بطاقات وجهاً لوجه في جدول مقارنة تفصيلي يوضح الفروقات الهجومية والدفاعية ونقاط القوة وسرعات التأثير.

### 5. المفضلة والإعدادات والنسخ الاحتياطي
* إضافة أي بطاقة للمفضلة واستعراضها بضغطة زر.
* التبديل السلس بين الوضع الداكن والفاتح.
* اختيار حجم البطاقات (صغير، متوسط، كبير) وطريقة العرض (شبكة أو قائمة).
* تصدير واستيراد كامل بيانات المستخدم (المفضلة + المجموعات + الإعدادات) بملف واحد.
* فحص سلامة الصور التلقائي لاختبار جاهزية جميع المسارات الـ 1,116 بنقرة واحدة.

## 🔒 الأمان والأداء

* **يعمل محلياً بدون خوادم خارجية:** لا توجد أكواد سرية أو مفاتيح API مكشوفة في الواجهة.
* **خالٍ تماماً من دوال `eval`:** جميع عمليات المعالجة آمنة ومعيارية.
* **أداء فائق:** تحميل تدريجي للصور (Lazy Loading) مع تقسيم الصفحات (Pagination) لضمان سرعة تصفح فائقة بمعدل 60 إطار بالثانية حتى مع وجود آلاف البطاقات.
